# .plans

Where plans and parked ideas live, so nothing raised during the build is lost.

| File | What it holds |
|---|---|
| `ideas.md` | Ideas for the product that are not being built now. Each one is tracked until it is picked or dropped. |
| `open-items.md` | Known gaps, faults, and follow-ups found while building and reviewing. Things that exist and are not right yet. |
| other `.md` files | A plan for one piece of work, written when that work is being thought through. |

The main build plan is still `PLAN.md` at the root.

## How it works

- Anyone can add an idea. Adding it does not mean it will be built. Picking is decided later.
- Every entry has a status: **Parked** (kept, not started), **Picked** (being built or built), or **Dropped** (decided against, with the reason).
- Nothing is deleted. A dropped idea stays, with why it was dropped, so it is not raised again from scratch.
- An entry says where it came from and why it is parked, in a line or two. Enough to pick it up cold.
- Agents do not act on anything here unless told to. This folder is a record, not a to-do list.
